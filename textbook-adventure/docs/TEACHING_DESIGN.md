# 教学设计

具体立体 → 改变观察位置/展开角度 → 预测 → 操作验证 → 数字与空间关系 → 独立练习 → 换数字迁移。

## 场景1：换个位置看一看

保持模型固定，位置小图中的观察机器人移动；主视窗展示该位置的视图，使用相同模型的六面变换。孩子点前后左右上下进行验证。原模型前1、右3、后6、左4、上5、下2；六面均不同，三组相对面数字和为7。新题前2、右1、后5、左6、上4、下3。

步骤2结束在关键提问前停住：正对前面，看到哪个数字？不能跳至后续步骤拿答案。第一次错误提醒方向；选择5时特别提示不要混淆上面和前面。第二次请操作方向按钮；第三次显示该题验证结果并提供相似题重试。正确后独立练习后面数字，再用新排列求左面数字。独立题中点击模型/方向会标记辅助，不宣称独立完成。

## 场景2：纸盒的六面旅行

六个有标记的面沿五条固定铰链展开。中央前面四周连左右上下，后面连在上面的外边。平铺是合法的六面十字展开图。拖动0～100%滑块可比较中间状态，模型面数不变，数字跟随所属面。

主问题判断中央面的对面；初错提醒“相邻”与“相对”的差异，选3/4触发相邻面提示。第二次引导折回；第三次完整验证并换题。独立题判断上面的对面，迁移使用新数字判断右面的对面。

## 状态与门控

INTRO → OBSERVE → QUESTION → HINT_1 / HINT_2 / EXPLAIN → RETRY → TRANSFER → COMPLETE。

QUESTION阶段自动暂停；未作答不可继续后半段。帮助按钮是明确求助，不自动判正确。正确后才显示下一阶段按钮；第三次错误可以换相似题，原失败记录仍保留。重播重置动画，不覆盖首次作答。每题1～6按钮和数字输入可任选，不要求键盘。

## 评价边界

首次作答、提示、演示后的正确结果分别记录；不把看过、点过或最终答对推断成稳定掌握。口头“为什么”由孩子讲给家人听，V1不识别语音、不自动评价开放解释，不作医学或心理诊断。
