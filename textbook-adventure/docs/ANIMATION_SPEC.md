# 动画规格

- CSS原生3D，六面DOM面板，自带颜色与中文面名，无外部图片/模型/CDN，无WebGL游戏引擎。
- 数学模型保存六面标签、相对关系和方向；视图角度与时间独立保存。正确答案来自数学引擎，不通过DOM数量推算。
- 观察：前(0,0)、右(0,-90)、后(0,-180)、左(0,90)、上(-90,0)、下(90,0)，X/Y角度单位为度。小位置图对应机器人移动，主视图是观察相机坐标变换。
- 展开：前面固定；左右绕Y轴±90°、上下绕X轴±90°，后面是上面子铰链，完全折叠时合成180°。角度由unfoldFaces生成。所有面共享边长；6个面始终保留，未复制或增减。
- 所有面板backface-visibility:hidden，保证封闭纸盒只看到外侧。折好前/右/上与空间数学模型一致。
- 播放速度0.6/1/1.5，同时改变步骤等待和CSS过渡时长。动画约1.4/速度秒，文字步骤至少2.2/速度秒；语音可用时等语音结束再开始步骤计时，是保守完成屏障，并非毫秒级对齐。
- 暂停清理自动计时，使用document.getAnimations()暂停正在运行的CSS变换；继续恢复。切步、重播、离课取消旧语音，代数计数器阻止旧回调更新新步骤。标签页隐藏暂停。
- 重听当前讲解会停止自动推进。默认静音；点击开启后才尝试原生中文语音。不支持或出错可继续文字；单段15秒超时回退，不能保证每台设备都有中文声音。
- respects prefers-reduced-motion: reduce：过渡近乎即时，数量/方向/门控不改变。
- 不实现任意剪切拓扑、自由摄像机、全套正方体展开图或物理碰撞引擎。滑块是受控合法展开过程，不是可任意撕开的纸张模拟器。
