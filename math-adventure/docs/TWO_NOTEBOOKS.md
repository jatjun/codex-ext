# 两份新错题本动画 · V1.3

对应用户提供的《01时25分33秒》与《01时24分05秒》两份PDF，各13页、25题。已逐页查看题目图像并核对答案；不依赖会丢失数字的PDF纯文字提取结果。两份PDF、手写答案、原书照片与个人资料均不提交到仓库、不发布到网站。

## 使用方法

首页点击 **进入两份新错题本**。A册是第一份（01:25:33，质量与应用），B册是第二份（01:24:05，运算与空间）。按原题号选择 → **开始探索** → 观看物体变化 → 操作场景 → 作答 → 独立迁移。

每题顶部展开 **调整数字、尺寸或方向**，输入后点 **应用设置，重新开始**。题干、模型数量、答案、提示、选项及迁移一起更新。非法设置不覆盖当前题；刷新恢复原始数字，历史答题记录保留。

手机中复杂场景可在画面内横向滑动，网页本身不横向溢出。折叠题可切换“查看图A/B/…”、拖动折叠角度，再“选A/B/…”提交；查看图不等于选为答案。轴对称题可亲手对折；玫瑰题只移动花朵，与灰色目标轮廓比较。

## 可调项目与保护条件

- 质量题可改吨/千克/克数量、瓶重、杯数、米袋质量、估算物体数量等。平均杯重要求整数克；总米重需能整除每袋质量，最多100袋。
- 重复组题可改每份两类数量、份数/人数/船数、价格、优惠、年级或每组人数等。动画物体总量最多120，班级与花束等需要能平均分完。
- 相向跑可改总距离、两人速度、时间；仅演示相遇前或刚好相遇，拒绝穿过对方后仍套原题公式的设置。
- 乘除题通过商与除数生成被除数，避免随意输入导致不适合本练习的非整数。最后除法需要整除；括号内的和必须小于外部被减数。
- 正方体可改棱长、观察角与选项排列；长方体演示长×短×短，可改两类边长、观察角和排列。图形是否可折由几何运算重算，不绑定固定字母。
- 观察题可改底层长度、叠层高度、目标方向和初始角度。若不同方向投影相同，接受任意一个数学上正确的方向，不强行判错。
- 平移、旋转可改距离、角度和方向；对称题可改尺寸、整体角度及图形顺序；玫瑰可改方向、大小与排列。
- 选择题的标准答案由当前数据生成；独立练习与提示后的相似题使用不同模型。没有新计算的重复子题优先从独立迁移中排除。

## 架构与数学规则

`src/notebooks/model.ts` 保存50个地址、共享题型、参数、校验、题干、答案及变式生成。A23～25映射B1～3；A16复用原21题中的第11题模型。入口和学习记录仍分别保存，重复题不会覆盖旧记录。

`geometry.ts` 的折叠算法从平面矩形相邻关系建立树，围绕共享棱旋转局部基向量和中心，得到每个面的真实3D顶点。完整折叠后要求六个不同法向、各面恰好覆盖包围盒边界且尺寸吻合，检测重合、缺口和断开的面。单元测试穷举35种自由六连方，验证恰好11种正方体展开图，并检查多组长短边比例。

投影从明确的体素坐标生成，去掉同一投影位置的重复格；相机的俯视与正视轴由测试校验。轴对称由多边形边、线段和圆心的镜像匹配检验，风车/光圈的旋转规律不会被误判成轴对称。玫瑰匹配同时检查转角、镜像与尺寸，允许平移的位置差。

运算使用结构化表达式树递归求值，**不使用eval、Function或大模型猜答案**。动画卡片与树节点对应，提示阶段可观察中间运算，完整讲解才显示最终结果。

`Scene.tsx` 使用SVG与现有动画时钟，不增加3D或动画运行依赖。手动运动也使用可暂停的rAF；结束准确停在目标值。自动观察、语音完成屏障、教学状态机、逐级提示、重试、迁移和首次作答保留复用原 `PdfSession`，扩展参数为可选，不改变旧题接口行为。

## 学习记录与新增题目

继续使用 `localStorage['math-adventure.records.v1']`。新ID为 `book-a-1`～`book-a-25`、`book-b-1`～`book-b-25`。记录原参数、当前场景、题干、第一答案、提示、是否看完讲解、迁移与实际交互时间，家长手记可导出JSON/CSV。每台设备、每个浏览器独立保存，不向服务器上传。

添加新题时：在地址目录中加题号和标题，定义参数与校验，构建数学模型和主线/迁移，选择或新增动态场景，再补数学与实际物体数量测试。折叠、投影、对称等必须由几何数据推导答案，不能只写固定答案与一段装饰动画。
