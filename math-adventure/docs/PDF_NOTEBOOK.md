# 错题本动画 · 2026-10-22

本次依据用户提供的12页、21题错题本逐页核对，原PDF、截图、孩子身份资料均不随网站发布。所有图形使用本地SVG基本部件重绘，人物是虚构称呼与通用卡通图标。

## 如何使用

首页 → **进入错题本动画** → 选择原题编号 → **开始探索**。先看动画，再点物体做标记或选商品，再提交答案。答对后才可下一步；完成原题后，必须完成数字或条件不同的独立迁移。不会时主动请求帮助。

每题上方展开 **调整本题数字**，修改后点 **应用数字，重新开始**。非法设置不改变当前题。刷新恢复原始数字，旧作答记录保留。不同型号手机显示的系统卡通图标可能略有不同，但标签、数量和规则相同。

## 数字范围与约束

- 图形：每种1～10个，总计不超过40。一个数组元素对应一个SVG部件，标准答案由数组生成。
- 动物/伙伴队伍：3～12位，位置不得超过队伍总数。比赛可改主角位置和左右方向，数组按从前到后排序，显示坐标由方向决定。
- 立体积木：保留原12件，可追加0～5个正方体，左右名次随总数重算。
- 球：每堆1～12；鸡蛋剩余1～20、吃掉1～12；椅子总人数2～30、已有1～29且小于总数；两车总人数2～30、小汽车1～6且小于总数。
- 商品：单价1～99，满减门槛2～200、减免1～99且不超过门槛；至少存在选1～3件达到门槛的方案。
- 满减规则：每笔订单满门槛（含相等）减一次，不采用“每满再减”。自选方案允许同款，总件数1～3。
- 购物答案同时校验真实购物篮、购买条件和输入价格；只背下答案但没有正确选商品不能过关。

## 教学与工程规则

沿用共用教学状态机：INTRO、OBSERVE、QUESTION、HINT_1、HINT_2、EXPLAIN、RETRY、TRANSFER、COMPLETE。第一错只给方法提醒；第二次显示分组/编号；第三次完整动画与讲解，之后先做相似题重试，再回原题。相似题重试使用第三套模型，不与后续独立迁移复用，以保留迁移结果的独立性。下一步不能跳过作答。迁移没有提前展示答案。

动画使用共用 `useAnimation` / `Timeline` / `Narrator`，每段语音与画面完成后再推进。暂停同时停动画、语音和计时；隐藏页面自动暂停；切换入口取消上一题语音与rAF。重播重新计算物体位置，不追加数组。快速点击锁避免重复提交。

手机中复杂拼图和长队伍采用**场景内部横向滚动**，保持图形、文字和触点清晰；网页本身不横向溢出。按钮至少44px。支持键盘Enter/空格和系统减少动态效果。无新运行依赖，无在线图片服务、云端学习记录或AI调用。

学习记录继续保存在 `localStorage['math-adventure.records.v1']`，levelId 为 `pdf-1` 至 `pdf-21`；包含原题/迁移独立ID、题干、参数、首次作答、提示、完整讲解、事件、结果及交互用时。家长手记增加21题完成统计，可按原有方式导出JSON/CSV。后续正确不能覆盖第一次错误。

## 文件与扩展

- `src/pdf/model.ts`：结构化数据、图形部件、21题生成器、可调参数、校验、迁移、作答校验。
- `src/pdf/Scene.tsx`：部件拆分、前后位置、立体形状、数量物体、商品购物篮。
- `src/pdf/Lab.tsx`：入口、参数编辑、教学会话、学习记录。
- `tests/pdf.test.ts`：数学与数量单元测试。
- `tests/e2e/pdf.spec.ts`：21题原题及迁移通关、提示/重试、暂停/重播、修改数字与非法配置。

增加新题时先定义数据与数学关系，再添加场景和独立迁移；新增目录卡、报告标签，并补充物体数量与真实交互的测试。避免只增加文字题干而没有对应的数量模型。

## 已知限制

图形是原题基本部件重绘；不提供PDF自动识题、语音识别或手写识别。手机复杂场景需要在画面内横向滑动。独立变式是确定性生成，不是无限随机题库。浏览器语音需用户点击开始，中文音色与播放表现受系统影响，未代替真机试听。各设备的本地学习记录不会自动同步。
