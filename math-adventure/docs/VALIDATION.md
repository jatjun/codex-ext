## 浏览器端到端

执行命令：

```bash
PLAYWRIGHT_BROWSERS_PATH=/workspace/codex-ext/math-adventure/.browser-cache \
  npm run test:e2e -- --project=chromium --project=chromium-touch
```

验证项目：桌面Chromium与iPhone 13尺寸/触控参数下的Chromium。每个项目执行以下9个场景：

1. 玩具总价、总价意义、实际平均分、第一次答12、随后答6、独立迁移、原始记录保留。
2. 图形值、错误加法提示、10个能量点合并、乘法24、迁移11和28。
3. 20只动物按种类与生活环境分类，遗漏提示升级，12图案按颜色与形状分类。
4. 确认25个实心站位、单边5、总数25，迁移9个站位，先答8再答9。
5. 暂停后SVG不变，继续、连续重播、离开清理和刷新回地图。
6. 三次明确请求帮助后，完整讲解完成才开放相似练习；原题首次帮助记录与讲解观看状态保留。
7. JSON真实下载、小屏/横屏无页面横向溢出、损坏的localStorage可恢复。
8. 四关分别在320px竖屏与844px横屏检查页面无水平溢出。
9. 延迟语音完成事件时画面停在本段；完成事件后才推进；暂停和退出调用原生语音暂停/取消。

最终浏览器执行结果：**18 passed (55.5s)**，桌面9项、触控模拟9项全部通过。测试中的语音使用确定性事件替身，验证屏障和控制，不证明系统中文音色或扬声器播放。
