# V1.1 排队动画与可调整数字

## 八类题型

| 题型                       | 默认条件                                                | 数学关系与默认结果                                  |
| -------------------------- | ------------------------------------------------------- | --------------------------------------------------- |
| 1 两头数求总人数           | 小明从前第5、从后第8                                    | 5＋8－1＝12；同一个人只数一次                       |
| 2 求另一头名次             | 共15人，小明从前第5                                     | 15－5＋1＝11                                        |
| 3 两人从不同方向计数的间隔 | 共15人，小明从前第5，小红从后第6                        | 小红换成从前第10；10－5－1＝4                       |
| 4 已知间隔求队伍人数       | 小红从前第8、小明从后第3、中间3人                       | 默认条件只允许小红在前，8＋3＋3＝14                 |
| 5 四方向的实心队列         | 左第6、右第5、前第3、后第6                              | 每行10人、8行，10×8＝80；是长方形，不能硬画成正方形 |
| 补充1 同方向的间隔         | 共15人，小明从前第4、小红从前第12                       | 12－4－1＝7                                         |
| 补充2 加入与离开           | 原15人，小明从前第5；队首先加入2人，再离开1人，小明留下 | 新名次5＋2－1＝6；新总数15＋2－1＝16                |
| 补充3 交换位置             | 共15人，小明第5、小红第11，交换位置                     | 小明从前第11、从后第5                               |

“方阵”在口头题目里有时泛指行列队伍。第5题四个名次得到8行10列，因此使用“实心长方形队列”；原有操场关卡仍保留正方形方阵教学，不改变其数学含义。

## 已知间隔题的先后顺序

设小红从前第a，小明从后第b，中间k人：

- 小红在前：总人数a＋k＋b。
- 小明在前：总人数a＋b－k－2；还必须检查每个名次是否落在队伍内。
- 未说明顺序：枚举并验证两个情况，不能暗中添加条件。

例如a＝8、b＝8、k＝3，两个合法总数是19和11。动画可切换两种队伍，系统要求同时写出两个答案；支持“11、19”“19，11”“19或11”等输入。只写一个不会通过。

默认a＝8、b＝3、k＝3时，反向候选总人数为6，小红却排第8，不能成立；因此默认只有14这一种答案。

## 动画与操作

- 一维队伍中每个人都有稳定ID；人物从队外移入，方向计数逐个出现1、2、3……，不会把前后名次当作两个人。
- 长队伍在场景内部横向滚动；自动计数时跟随当前人物，手机可左右滑动，不挤成无法辨认的小点。
- “中间”只高亮严格位于两个端点之间的人；端点不计入。
- 实心队列生成行数×列数的所有站位，内部有人；四方向沿同一行或列数到小明，再逐行高亮。
- 加入题先让新朋友移到队首、原队员后移，再让队首人物离开、其余人前移。条件限制不会把小明移出队伍。
- 交换题保留小明、小红的身份ID，让两个人实际走到对方的位置，其余队员不换位。
- 支持手动“从前/后/左/右数一步”、点击人数或行数标记、清空标记、暂停、重播及逐级帮助。
- 使用现有动画时钟与分段语音屏障；暂停时人物移动、计数、语音和用时均停止；离开页面清理时钟与语音。

## 修改数字

每关顶部的“调整本题数字”可以随时展开：

1. 输入本题所需数字；题型4还可选择“未说明顺序”“小红在前”“小明在前”。
2. 点击“应用数字，重新开始”。
3. 校验通过才生成新题，并同步更新人物数量、位置、题干、提示、语音、算式与答案。
4. 不合法输入会给出说明，原来进行中的题目保持不变。
5. 应用新数字创建新学习会话，旧记录保留。迁移题会自动生成另一组合法数字。

设置适合家长或老师备题，孩子作答时可以收起。当前设置只保存在页面内存中；刷新后恢复默认数字，历史学习记录仍保留。

### 原四关也支持调整

- 玩具商店：购买数量、单价、另一位孩子的购买数量；总价最多24元，要求整元平均分。
- 图形密码：图形个数和每个图形的能量，自动生成题干总能量；每组总能量最多30点。
- 分类：三种动物各1～10只，以及6、9、12、15、18个迁移图案；结构化数据生成全部对象，计数守恒。
- 正方形方阵：中间的人从每个方向第1～5，对应1～9行/列的实心方阵；迁移题同步换数字。

这些范围用于保证小学整数数学与屏幕可读性，不会悄悄把无效数字改成另一道题。

## 记录兼容

沿用原localStorage键，不删除V1历史。在新记录上增加题干快照、参数快照、专题名称及本轮必做题ID。家长报告包含排队专题，导出JSON/CSV带题干和参数。

同一题型改了数字后，之前的第一次答案和正确性仍属于原会话；新会话不会覆盖它。旧版本缺少新字段的记录仍能读取。

## 开发入口

- `questions/models.ts`：参数类型、范围、默认值、八类入口。
- `questions/queue.ts`：排队数学、条件校验、动画步骤、迁移数字、多答案比较。
- `questions/builders.ts`：根据参数生成关卡和题目，生成动物、图案。
- `components/Configuration.tsx`：数字编辑与题型选择。
- `components/LevelSession.tsx`：共用教学状态、语音、答题、记录。
- `scenes/QueueScene.tsx`：一维移动、交换、加入/离开和二维实心队列。

新增题型必须同时实现数学模型、合法性校验、动画、提示、独立迁移及对应测试，不能只加一段题目文字。
