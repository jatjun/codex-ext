# 教学设计与数学正确性约束

V1.1增加八类排队动画与原四关的数字调整。下文数值是默认示例；参数变化时模型、题干、动画、提示、语音与答案同步生成。排队专题的数学规则及多解处理见 [QUEUE_DESIGN.md](QUEUE_DESIGN.md)。

## 共同教学流程

`INTRO → OBSERVE → QUESTION`，按需进入 `HINT_1 → HINT_2 → EXPLAIN → RETRY`，完成原题后进入 `TRANSFER → COMPLETE`。

单独点击下一步不能跳过问题。孩子需要提交想法或明确请求帮助。第一次未答对给思路，不泄露结果；第二次用物体提示；第三次完整演示，要求做相似小题后回到原题。原题全部完成后必须完成独立迁移。错误只当作观察线索，不惩罚、不做能力标签。

语音和动画采用分段完成屏障，每段两者完成后才推进；没有语音时使用同样文字与画面步骤。暂停固定当前数量和位置，重播从新的时钟起点开始，切换关卡清理时钟与语音。

## 1. 玩具商店

**目的**：区分数量、单价、总价；理解“花的钱一样多”指总价相同，形成先乘后除的两步关系。

- 4只玩具逐只入篮，每次支付3枚金币，收银台依次3、6、9、12。
- 支付过程中不展示尚未成立的等式；完成付款后展示4×3＝12。
- 12枚原有金币移动到乐乐分配区，没有产生新金币。每枚金币只有一个位置。
- 孩子必须先回答总价，再判断12元的意义，最后亲手分完12枚金币，两份相等且各6枚，输入6才通过。
- 回答12时，先问“12元是两个玩具的总钱数，还是一个玩具的钱数？”；回答4或未分完时，引导检查剩余与两边数量。
- 第二层演示逐枚轮流分配；不是直接把两个计数器写成6。
- 迁移：3×4＝12，12÷2＝6。题干不显示答案，迁移首次状态独立保留。

**不变式**：总枚数始终12；每个已分配位置只接受一枚；所有金币分完且两份相同，才满足平均分。

## 2. 图形密码

**目的**：先求符号值，再识别运算符号；针对“6＋4写成12、6×4却能算对”的不同理解进行检查。

- 三颗星星对应18点，平均移动到三个同大格子，每格6点。
- 四个三角形对应16点，平均移动到四个格子，每格4点。
- 单独验证☆＝6和△＝4后，才进入运算台。
- 加法显示6枚紫点和4枚绿点；合并时保留全部10枚，并用1～10逐个编号。第一次答12只提醒加号意义，不弹出正确答案。
- 乘法显示6行、每行4点，共24点，区分“合并两份”与“几组相同的数”。
- 迁移：○＋○＝14、□＋□＋□＝12；先求○＝7、□＝4，再得和11、积28。

**不变式**：均分前后点数守恒；组数×每组点数＝总数；加法点数10与乘法点数24使用各自模型，不复用错误数量。

## 3. 分类小侦探

**目的**：遵循一个分类标准，不漏数、不重复；换标准后总数保持不变。

- 固定数组20个唯一ID：蝴蝶8、蜻蜓6、鱼6；轻微翅膀、飞行、水游动态不改变站位数量。
- 支持拖动和“选一个物体→点击分类框”；分类后仍能选中物体更改位置。
- 计数器由实际放置数组推导；一个ID只能对应一个分类，不可能在两个框重复计数。
- 首次检查缺失只提示总数20与当前找到多少，不点名具体漏掉物体。再次错误才给未分类物体描边。
- 第三次提示逐个演示正确分类，再做相似数量题，回到原题自己分类。
- 第二阶段重排同样20个ID，按环境分类：飞行14、水游6。两阶段都要检查完整性与类别正确性。
- 迁移固定12个颜色/形状图案，三种颜色各4个，三种形状各4个；两次分类都要交互完成。

**不变式**：物体总数固定；任一时刻“未分类＋各组数量＝总数”。只达到总数但类别错误也不能通过。

## 4. 操场排队

**目的**：理解从两边数到同一个中心会重合一次；区分每行人数、行数、总人数；明确实心而非空心。

- SVG真实二维5行5列，共25个站位，小朋友逐行、逐人入场。
- 中心坐标(2,2)用不同衣服与头顶标记；四方向各沿中心行/列动态标记1、2、3。
- 四方向所指始终是同一个中心，不是四个不同的人。
- 一列：前2＋中间1＋后2＝5，或3＋3－1＝5。
- 一行5人，共5行；逐行高亮，得到5×5＝25。
- 内部9个位置实际有人，不允许只数外框16人。
- 迁移展示真实3行3列，中心从四方向数均第2。首次答4或8，先数一行人数与行数，不提前显示9。

**不变式**：边长＝2×中心名次－1；人数＝边长平方。原题5²＝25，迁移3²＝9。

## 学习证据

首次答案、首次正确性与迁移首次结果不可被看提示后答对覆盖。首次请求帮助记为“需要帮助”；相似练习不冒充原题首次结果。报告同时展示原始状态、帮助次数、完整讲解观看情况和最终完成状态。

“完整讲解看完”只在动画与本段语音屏障结束后记录，暂停或提前离开不记为看完。各百分比显示分母，空记录显示暂无作答。交互用时排除暂停、隐藏页面与长时间无操作，不能解释为标准化能力分数。
