# 语文教学设计 V1

## 学习路径

故事与方法示例（INTRO→OBSERVE，三个观察片段）→孩子作答（QUESTION）→轻提示（HINT_1）→回看图形（HINT_2）→完整参考与讲解（EXPLAIN）→相似题（RETRY）→原题→独立迁移（TRANSFER）→小结（COMPLETE）。不能用“下一步”跳过未完成的作答。主动请求帮助也逐级展开，不使用惩罚。

示例动画和待答题明确分开。11类共享知识模型服务125个原题入口，不代表125段逐字复刻原题的独立动画。书籍知识、字词记忆等仍需要读题和作答；动画用于理解相关方法，不虚构课文故事或靠动画代替必要的识记。

## 动态模型

|模型|真正变化的对象|孩子的操作|
|---|---|---|
|拼音|声母、介母、韵母积木逐步靠近、拼合|切换火/显示例；拼音输入；按类移动音节卡|
|汉字|偏旁与共同部件靠近组合，形成清、请、晴并联系词义|选字、改错、组词；比较偏旁和意思|
|句式|小猫移动并推动球，主动者与承受者不变，句子视角改变|把/被句词卡重排，选择保持意思的句子|
|故事排序|小猫进入秋日农场、移动捉迷藏、睡觉|重排故事片段；错误顺序需要再试|
|关联词|雨滴下落、雨伞展开、角色在雨中前进|辨别原因结果、转折、条件、选择等关系|
|反义词|门板开合、通道宽度改变|填反义词，迁移到新的反义词|
|地图|角色从大门沿路径向北、再向东移动|根据方向词选择地点，再描述自己的路线|
|表达|云朵平移，显现绵羊和小鱼的形象变化|写比喻、动作、感受，逐项自查|
|声音|可见声波扩散，随情境显示鸟叫或门声|拟声词配对；不宣称已提供真实音效|
|查字典|部首与剩余部件移动到字典两侧|区分音序、部首、剩余笔画、语境义|
|故事阅读|小兔走近小伙伴、观察与交流|回忆书中线索，写合理表达|

卡片分类使用稳定的数组索引，归类后卡片实际从待分类区域进入分类框；支持重新选择已归类卡片，数量保持不变。移动使用Web Animations API；减少动态设置下取消移动过渡。所有示例进度由同一rAF时钟控制，暂停冻结进度。

## 开放表达

造句、比喻、口语交际不以参考句全文匹配。孩子先提交，原始表达立即保留，再逐项自查；参考表达默认折叠。完成自查仅表示孩子确认检查过，`firstCorrect=null`，不计入正确率。不提供大模型语义评分，也不声称能识别所有语病。

填空和选择是明确范围的题，拼音保留声调、ü及大小写差别；仅忽略空白及常见句末/分隔标点。形近字不会按同音宽松通过。扩句保持主干动作，把/被转换保持施事和受事。反问的理解联系上下文，不能仅凭问号下结论。

- 第4册第4题、第5册第6题带“吧”的仿句按建议语气教学，不沿用“仿写陈述句”的混乱标签。
