# 原题目录与三科错题本

## 使用

共同首页新增「打开我的三科错题本」，三科页面页眉都有「我的错题本」。数学首页新增「按题型找原题」：260个入口跨上传批次归类，保留来源册号和原题号；其中1题仍待核对，不能开始。搜索可匹配标题、题干、条件和来源，分批显示，避免手机一次渲染全部卡片。

数学各教学页常驻原始条件、具体数字、静态题图和问题；改数字后原始条件仍保留，下方当前题目随设置变化。演示后显示当前完整条件及需作答的小问，沿用真实物体互动、分级提示、强制相似题和独立变式，不靠点下一步直接获得答案。

## 错题收录与复习

- 三科客观题只在实际提交过错误时自动收录；没有作答和只点击求助的记录不冒充错答。
- 按学科、题型、来源查看，可搜索，筛选待巩固、已复习或全部错题。
- 同条件同小问合并展示，展开可见所有历史提交；数字不同的数学题分开。
- 原始首次答案不覆盖、不删除。“我复习过了”写入单独的状态键，可撤回；这只是自行标记，不等于系统确认掌握。
- “回到这道题重做”建立新的练习会话。数学新记录保存题目、场景和条件快照，优先准确还原；语文、英语按来源、阶段和小问进入。听力重做仍需听完或明确使用文字辅助。
- 口语、自由表达与创作不自动判错，单列作品自查。系统没有语音识别或通用语义评分。
- 可导出当前筛选JSON。导出含本地作答，请自行保管。

## 旧记录边界

原有记录不迁移、不改写。旧语文/英语原题可借题库补上小问题干；没有阶段题干的旧相似题、迁移题不会误套原题文字。数学旧记录尝试用保存的参数和题库核验还原；缺少关键条件、题干或无法匹配时展示原记录并提示，通过来源原题重新学习，绝不猜出一道不同的题。

新数学记录增加questionSnapshot/lessonSnapshot/storyText；新语文、英语记录增加questionText，均兼容旧数据。原始PDF、照片、手写作答不发布。

## 文件与保存位置

- `math-adventure/src/library/`：260入口、分组搜索、原题展示及数学错题还原。
- `learning-home/mistakes.html`、`mistakes.js`、`mistakes-model.js`、`mistakes.css`：三科共用错题本。
- `learning-home/learning-catalog.json`：只有题目文字、来源与分类，无标准答案或孩子数据。
- `scripts/build-learning-catalog.mjs`：生成共享目录；新增题目后从仓库根执行`node scripts/build-learning-catalog.mjs`。需要先安装数学工程依赖。CI用`--check`防目录遗漏。
- 三科原localStorage键保持不变：`math-adventure.records.v1`、`chinese-adventure.records.v1`、`english-adventure.records.v1`。
- 复习标记：`learning-garden.review-status.v1`。

必须在同一网站来源和原来设备/浏览器使用；清理数据、无痕模式和跨设备不会自动同步。未建立账户和服务器学习档案。已有正确记录不会凭空出现在错题列表，刚打开空白是正常的。

## 验证

单元检查目录数量/唯一性/待核对题、还原数学条件、旧记录降级；共享逻辑检查收录规则、同条件合并、首答保留、作品单列及URL不包含作答。浏览器检查分类/搜索/来源原题、三科收录、标记与导出、数学快照重做、语英准确小问深链接。沿用三科完整回归和Pages组装，实际结果见本次Actions与交付；没有执行的设备测试不得标为通过。

## 勾选显示范围与隐藏已会的题

数学按题型目录、原有各题本和排队入口，以及语文、英语目录，都有“显示这题”勾选框。取消勾选只从通常的目录隐藏，题目和历史记录仍保留；深链接也仍然可打开。

点击“查看全部（含隐藏）”，可以找到未勾选的题并重新勾选；再点“只看勾选的题目”恢复通常视图。可批量显示或隐藏当前筛选中的题；批量隐藏后会自动进入查看全部，便于只勾选想保留的题。三科设置互相独立，数学不同入口使用同一个题目ID同步显示范围。

错题本也有独立的“显示这道错题”勾选框，以及“查看全部（含隐藏错题）”。隐藏来源题目不等于隐藏实际错题，两者可以分别管理。复习标记和显示勾选也分别保存。

显示偏好保存在当前浏览器localStorage键`learning-garden.visibility.v1`，刷新后保留，清理网站数据或换设备后不自动同步。保存失败会明确提示，不会伪装成已保存。共享规则在`learning-home/visibility-model.js`，三科React组件只负责界面。
